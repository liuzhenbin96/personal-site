# Zhenbin Liu Personal Site

A static bilingual personal brand website built with HTML, CSS, and JavaScript.

## Local Preview

```bash
cd personal-site
python3 -m http.server 4173 --bind 127.0.0.1
```

Open:

```text
http://127.0.0.1:4173
```

## Structure

```text
personal-site/
  index.html
  styles.css
  script.js
  assets/
    avatar.png
```

Replace `assets/avatar.png` with a real portrait when ready. Project copy can be edited directly in `script.js` for both Chinese and English versions.
